# CGA 选项计分与报告显示修复审查

## 核对范围
- 基线：已包含 CGA 报告单的 `main`（合并提交 `33e92b9`）。
- 本分支：`fix/cga-report-score-recalculation`；未修改 `main`。
- 涉及 AI 选项快照计分、历史报告再生成、护士最终确认分数来源核对及 CGA 前端文本。

## 审查结果
1. 单选/多选题从真实选中的 `AssessmentAnswerOption.clinical_score` 累计，回写当前题目分数；非选择题沿用确实保存的题目临床分数，不叠加旧选项答案分数。
2. 必填题缺失、任一计分题漏答、选项无有效分值，或量表本身没有计分项目时，清除无效旧总分；显式 0 分必须照常保留。量表风险解释只使用该量表已存在的规则，不采用跨量表通用分数线。
3. 生成新版报告前重算可验证的历史 AI 选项得分，旧报告快照不改变。最终护士提交没有原生选项快照时，只有全部计分题与原提交的答案文本严格一致，才能复用历史得分；无法确认时显示未完成计分，不能把旧 AI 分数冒充护士确认结果。
4. 新报告快照显式传递 `score_status`，前端去重 `result_summary` 与 `scores.interpretation`，并区别“未完成计分”“未进行相关量表”和真实 0 分。
5. 已新增后端选项计分、风险规则、答案同源检查回归测试以及前端结果格式化/状态测试，且修正了原测试中无得分睡眠量表的状态预期。

## 部署验收
1. 在 Windows 本地或 CI 执行：`cd backend; uv run pytest tests/unit-test/test_assessment_option_scoring.py tests/unit-test/test_assessment_report_score_source.py`；随后执行 `cd frontend; pnpm test -- assessmentReportView.test.ts; pnpm typecheck`。
2. 部署修复分支或其后续合并版本之后，在有权限的医护端打开任务 84 报告，点击“重新生成”创建新报告版本；仅刷新旧报告不会变更历史分数。
3. 对照数据库中的真实已选项快照核对总分；若护士最终答案与旧 AI 选项不一致且没有完整可计分信息，新版显示“未完成计分”，需进一步完善护士确认的结构化选项保存流程。
4. 确认报告里每段通用解释只出现一次，真实 0 分原样显示；不要用真实患者资料作为公开回归测试数据。
