# 隐藏患者住院信息区块验证

## 改动
- 新增/编辑患者表单整块移除本次住院信息，不再显示科室编码、科室、病区、住院状态和医保类别；同时不保存隐藏字段的本地表单值、不校验或提交这些字段。
- 新增科室默认未指定、病区默认未分配、状态在院，科室编码和医保缺省为空；编号、日期、床号、来源与护理级别沿用系统自动规则。
- 临床诊断和过敏摘要仍按原接口保存在住院记录上；编辑提交住院记录 ID 和临床摘要，省略隐藏字段，保留历史信息。
- 前后端及 Mock 对省略字段、显式值和历史空值的语义保持一致，无数据库迁移。

- 真实 PostgreSQL 集成测试 1 项通过：新增省略住院区块字段，独立数据库会话查询主档及住院记录，确认科室/病区及其他默认值持久化，编辑后保持不变，finally 清理本次自建记录。
- 后端相关文件 Ruff 通过，集成测试仅现有 Redis close 弃用警告。
- 独立审查无阻塞发现。
- 页面隐藏由真实 React 表单渲染测试同时覆盖新增和编辑；浏览器端到端验证受现有医护会话限制，本轮未把静态渲染测试描述为浏览器验证。
