# 医护监控布局与结构化答案真实值修复审查

日期：2026-08-19

## 1. 审查结论

- 结构化答案已从“直接展示选项编码”改为“后端返回量表标签/值，前端统一展示真实值”。
- `selected_options` 继续保留，作为抽取结果审计与选项关联信息，不再进入用户可见文本。
- 患者端与医护端共用统一展示函数，可信度、证据消息 ID 和患者纠正入口保持不变。
- 医护监控页已经按原型形成顶部患者摘要和左/中/右三栏；工具结果仍在对话时间轴中完整回放。
- 当前未处理呼叫会在对话回放底部显示紧凑提示栏，并区分患者主动呼叫和 AI 工具呼叫；处理后历史卡片继续保留。

## 2. 调试发现与修复

- 任务 109 的结构化答案历史接口原先只返回 `option_4`、`option_3`。修改后真实页面已显示“很少潮湿”“经常步行”“适当”。
- 医护监控页原先会复用 sessionStorage 中的旧任务快照，导致新增住院摘要字段不能及时显示。修改为 API 模式每次进入详情都刷新后端任务详情。
- SSE 快照事件使用 `snapshot:*` 作为浏览器事件 ID，断线重连时该值不能直接作为 Redis Stream ID。已在后端续读边界过滤无效 ID，并补回归测试。
- 目标量表状态不再由前端数组下标猜测，后端按每个 `assessment_instance` 返回真实已答数、总题数和状态。
