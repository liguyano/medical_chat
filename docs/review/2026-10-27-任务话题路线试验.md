# 任务话题路线试验审查

## 实现
创建任务同次模型调用生成 v2 路线，保存 Redis 与任务准备快照。文字和语音各入口共用路线。旧任务保留原流程；新路线需新建任务生成。

## 验证
- 后端单元测试：373通过（最终审查修复后再次验证）。
- 本次修改静态检查通过。
- 真实 Schedule 模型生成合成路线测试通过：娱乐视听→餐食/餐具动作→晚间休息；全部编码唯一覆盖。
- 真实语音供应商六轮均有ASR及音频：游戏→上一顿→面条→筷子动作→晚间休息。工具缺项结果模拟，不连接患者数据库，不是完整业务E2E。
- 语音行为断言未通过：第一轮出现反问兴趣后再问视力，第四轮同时问手顺不顺和扶碗，第六轮听得到吗后追加晚间问题。没有通过效果验收，不合并dev/main、不推送。

## 独立审查及修正
1. 混合话题只裁编码会暴露已完成题指导：部分完成时移除原入口、追问、分支及转场，改用仅剩事实的场景指导，回归验证不出现旧入口和旧追问。
2. 文字耗尽及communication模式无条件追加路线：加入模式限制，避免重新暴露完成目标或在通话确认中引入采集路线。

## 运行边界
未启动应用服务；测试进程已退出。用户现有服务不停止。试验版不承诺自然语言约束稳定遵守；后续可考虑逐轮决策与生成校验，不能只凭路线存在宣称自然聊天已解决。
