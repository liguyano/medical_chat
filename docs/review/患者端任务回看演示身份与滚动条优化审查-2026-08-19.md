# 患者端任务回看、演示身份与滚动条优化审查

日期：2026-08-19

## 1. 修改摘要

- 患者 API 联调登录页新增 10 位安装文档患者的一键填充按钮，数据集中维护在 `src/lib/patient/demoAccounts.ts`。
- 患者任务中心按“未完成任务 / 已完成任务 / 已取消任务”分组；`pending_review` 与 `completed` 均归入已完成区，避免患者误以为待复核任务仍未完成。
- 已提交或已完成的 AI 对话任务详情增加“查看对话记录”入口。
- 历史对话页面以只读模式加载：保留普通消息、宣教、知情同意、呼叫护士和结构化结果；隐藏输入框、纠正按钮、风险确认操作、暂停按钮和实时 SSE 状态，避免历史记录被误修改。
- 患者端页面滚动条、AI 对话中间滚动区、结构化信息侧栏统一使用细窄圆角滚动条样式。
- `deploy/Install.md` 补充快捷填充行为说明。
