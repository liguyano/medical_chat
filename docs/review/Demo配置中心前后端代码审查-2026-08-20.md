- [X] 登录医护直接查看、修改并立即生效。

## 三、审查结论

- [X] `/api/system-config` 全部路由均依赖医护登录认证。
- [X] 宣教工具从当前启用数据库材料读取，业务事件继续保存内容快照。
- [X] 拦截规则每次患者文本匹配前从数据库刷新，避免 API 与 Celery Worker 缓存漂移。
- [X] 无效正则在保存前拒绝；量表保存校验主从 ID 和关联范围。
- [X] 前端页面只通过 `CareRepository` 访问后端，并保留 Mock 演示能力。
- [X] 页面等待医护身份就绪后再加载配置，未登录访问不抢跑配置请求。
- [X] 未发现阻塞合并的高、中、低优先级问题。
