# 患者住院日期与真实入库验证

## 变更范围
- 护士新增、编辑表单移除入院/出院日期输入及状态选择。新患者默认在院，编辑保留既有状态。
- 新增请求不传日期时，后端 Schema 每次生成当前 UTC 入院时间，出院时间为空；显式历史日期继续兼容。
- API 省略未提供的日期，避免编辑时以 null 清空历史出院时间；Mock 新增补时间，编辑保留原日期。
- 无数据库迁移，无 main 修改，无远程推送。
