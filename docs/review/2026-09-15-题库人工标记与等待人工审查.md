# 题库人工标记与等待人工审查

## 审查结论

人工题使用 `validation_rule.manual_required: true` 作为题目元数据，不新增数据库字段。人工题不会进入患者答案、AI 调度、抽取、语音恢复题或必填进度，也不会触发护士呼叫接口。患者端、医护端和配置页均保留题目，并以“等待人工”显示；医护填写真实答案后显示真实值。

## 审查中发现并修复的问题

1. AI 得分曾可能把缺失的人工计分题按零分汇总。现改为人工计分题未取得真实答案时清除总分、风险和旧得分记录。
2. “人工必填题加自动可选题”曾无法进入复核。现以自动必填题为完成边界；没有自动必填题时直接进入待医护复核。
3. Mock 配置在跨页面后曾丢失人工标记。现由 Mock Repository 持久保存并统一生成问卷快照，行为与 API 模式一致。

## 验证记录

- 后端本次相关检查通过；单元与集成测试共 328 项中 327 项通过。唯一失败为既有迁移表数量断言期望 49、实际 50，与本次无迁移的变更无关。
- 前端 29 个测试文件、90 项测试通过，类型检查、代码检查和生产构建通过。
- 真实浏览器验证配置勾选后 JSON 保留原有校验项并增加人工标记；传统问卷显示 `0/6 · 等待人工 1 项`，人工题没有输入控件。桌面与 390×844 视图均可见，控制台无错误。
