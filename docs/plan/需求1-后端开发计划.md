## 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 模型推理不稳定 | 高 | 增加重试机制，超时降级 |
| Redis Stream消息丢失 | 中 | 消息持久化到数据库 |
| 字段抽取准确率低 | 高 | 优化提示词，增加人工确认 |
| 对话偏离检测不准确 | 中 | 调优Schedule Agent提示词 |
| SSE连接不稳定 | 中 | 心跳保活，断线重连 |
| Celery任务堆积 | 中 | 监控队列长度，动态扩容Worker |
