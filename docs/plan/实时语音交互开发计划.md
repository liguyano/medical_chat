## 设计约束

- 不修改文本 Dialog Agent 的生成逻辑。
- 不把音频二进制写入 Redis Stream。
- Qwen Audio Realtime 使用官方 `server_vad` 自动轮次；普通语音轮次不发送
  `commit` 或 `response.create`。
- Function Calling 严格执行 `arguments.done → function_call_output → response.create`。
- 真实模型联调需要真实百炼 API Key；单元测试使用协议级 Fake 上游，不把 Fake WebSocket 当作真实 E2E。
