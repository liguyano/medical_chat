# 禁用模型主动呼叫护士开发计划

彻底取消文字与语音模型调用 `request_nurse_assistance` 的权限，防止普通量表回答被误判为护士协助请求；保留患者端主动呼叫接口、固定人工审核通知和历史事件兼容能力。

## 1. 锁定权限边界

- [X] 1.1 确认误触发来自模型仍可见的 `request_nurse_assistance` 工具。
- [X] 1.2 确认患者按钮使用应用层 handoff 接口，不依赖模型工具列表。
- [X] 1.3 确认执行注册表继续保留旧工具，仅用于历史兼容和显式应用层调用。
