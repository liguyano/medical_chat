# 语音上游断线恢复开发计划

## 目标

修复 Qwen Realtime 因 keepalive ping timeout 关闭后，旧 `VoiceSession` 仍被继续使用、患者后续音频触发 `ConnectionClosedError` 的问题。断线后淘汰旧上游会话，患者端自动重连一次并根据数据库结构化进度继续评估；重连失败时保留文字输入。

## 基线与约束

- [X] 仓库不存在本地或远程 `dev` 分支，采用用户确认稳定的 `fix/voice-premature-close-recovery` 提交 `abe46f0` 作为基线。
- [X] 在隔离分支 `fix/voice-upstream-disconnect-recovery` 开发，不修改原稳定分支及其未提交文件。
- [X] 不修改 Qwen API Key、业务空间、模型或提示词。
- [X] 不自动启动前端、后端或 Worker。
