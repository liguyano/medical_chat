# 真实数据演示发布与恢复开发计划

## 需求目标

在现有本地构建 Docker 镜像发布流程基础上，允许将当前本机系统的真实
PostgreSQL 数据、对话音频和知情同意签名原样打包，上传公网服务器后恢复，
使浏览器访问正式域名即可复现本机演示状态。

Redis 不迁移本机运行态；服务器使用全新 Redis 数据卷，避免带入登录会话、
SSE 游标、临时 Agent 状态和 Celery 队列。
