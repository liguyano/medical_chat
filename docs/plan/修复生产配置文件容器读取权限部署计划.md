# 修复生产配置文件容器读取权限部署计划

## 需求目标

修复生产容器挂载 `config.production.yaml` 后出现
`PermissionError: [Errno 13] Permission denied: '/app/config.yaml'` 的问题。

## 开发步骤

### 1. 原因确认

- [X] 1.1 确认后端镜像以 UID `10001` 的非 root 用户运行。
- [X] 1.2 确认服务器配置文件被设置为 root 所有且 `0600`，容器用户无法读取。

### 2. 部署修复

- [X] 2.1 增加恢复前配置文件可读性检查和明确修复提示。
- [X] 2.2 更新安装手册，区分宿主机密钥文件权限和容器配置文件所有权。

### 3. 验证与交付

- [X] 3.1 校验 Bash、Compose 和文档命令。
- [X] 3.2 更新审查记录。
- [ ] 3.3 提交功能分支并合并本地 `main`。
