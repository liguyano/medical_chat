# 实时语音提前结束恢复方案

## 目标

在 Qwen Realtime 已经向患者播报完一轮回复后，对“提前使用结束话术”做事后检测；若结构化评估尚未完成，则自动恢复当前会话，仅下发一条合法下一题，让模型自然纠正并继续提问。保持原实时音频低延迟链路，不增加输出前审核。

## 设计边界

- 评估是否完成仍以 `assessment_progress_service` 的有效结构化答案为唯一事实来源。
- 结束语检测只判断 AI 可见回复是否具有结束意图，不负责判断题目是否完成。
- 恢复时保留现有 Realtime 会话上下文，不重复注入全部后续问题。
- 恢复轮只暴露一个系统选定的下一题，禁止模型自行浏览完整剩余题列表。
- 不改变现有语音完成屏障语义；真正完成仍由结构化完成 + 可见 `response.done` 协调。
- 第一版优先可调试、可观测和幂等，不做输出前拦截。
