# CGA 报告单样式改造计划

## 目标

将医护端 `/nurse/tasks/[id]/report` 从卡片式能力概览改造成接近医院纸质“老年综合评估（CGA）报告单”的结构化报告页面。

报告继续以持久化 `sourceSnapshot.assessments` 为真实量表来源，不修改原始量表结果。按照参考报告预置 CGA 评估目录；某个预置项目没有对应量表结果时，明确显示“未进行相关量表”。

- [X] 1.4 按参考报告整理 CGA 分区及预置项目，未匹配量表统一显示“未进行相关量表”。
