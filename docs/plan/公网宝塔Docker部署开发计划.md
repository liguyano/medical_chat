# 公网宝塔 Docker 部署开发计划

## 需求目标

使用宝塔宿主机 Nginx 负责域名、HTTPS 和反向代理，使用 Docker Compose
一键启动前端、后端、PostgreSQL、Redis、Celery Worker 和 Beat，供 Linux
公网正式环境部署。生产环境禁止自动导入演示账号和患者数据。
正式发布采用“本地构建 `linux/amd64` 镜像、导出镜像包、上传服务器、
服务器 `docker load` 后无源码启动”的方式。
