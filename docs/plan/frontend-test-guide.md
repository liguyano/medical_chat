# 前端可用交互原型测试指南

> 适用版本：2026-08-16 `feat/frontend-usable-prototype`

## 1. 启动与检查

在 `frontend` 目录执行：

```powershell
pnpm install
pnpm dev
```

默认访问地址为 `http://localhost:3000`。

提交前执行完整检查：

```powershell
pnpm check
```

该命令依次执行 ESLint、TypeScript 检查和 Next.js 生产构建。

## 3. 护士端验收路径

### 3.1 登录和导航

1. 使用演示账号登录。
2. 验证工作台、患者管理、任务管理、实时监控、AI质评和系统配置可进入。
3. 刷新页面，确认登录态不丢失。
4. 点击右上角用户图标，确认退出后回到登录页。

### 3.2 创建任务包

1. 进入“患者管理”。
2. 打开“陈丽华（405-2）”患者详情。
3. 点击“创建评估任务”。
4. 依次验证四个步骤：
   - 患者和参与人；
   - 多量表选择；
   - AI对话/传统问卷、评估场景、计划时间、宣教、同意书和备注；
   - 发布摘要。
5. 发布后确认进入新任务详情，能看到任务编号、患者信息和操作入口。
6. 再次对同一患者创建相同未完成任务时，确认出现重复任务提示。

### 3.3 监控、复核与质量评价

1. 访问 `/nurse/monitor/3`。
2. 验证对话回放、结构化答案、证据消息、风险/宣教事件和AI总结。
3. 对任意 AI 消息点赞或点踩，刷新后确认状态保留。
4. 将未处理风险事件标记为已处理。
5. 点击“进入护士复核”。
6. 修改任意护士答案，确认页面显示差异并要求填写修改原因。
7. 不填写原因直接确认，确认出现拦截提示。
8. 填写原因和补充问诊摘要后确认，任务进入已完成并跳转 AI 质量评价。
9. 填写总体意见并提交，确认显示“评价已保存”。

## 4. 患者端 AI 对话验收路径

1. 使用身份证号和手机号登录患者端。
2. 从任务中心进入医护端刚发布的任务，再进入 AI 对话。
3. 可按以下回答完成全部七轮：

```text
方便，可以开始
58
对青霉素过敏，曾经出现皮疹
下床时需要家属搀扶
半年内摔过一次，夜间起床有些头晕
每天吸5支烟
胸口偶尔发闷，担心夜间起床摔倒
```

4. 验证：
   - CICARE 阶段和进度更新；
   - AI回复分段呈现；
   - 过敏、防跌倒和住院禁烟宣教出现；
   - 宣教必须由患者主动确认；
   - “已记录信息”实时更新；
   - 暂停后输入不可用，继续后恢复；
   - 更正年龄后显示“已更正”；
   - “找护士”产生人工介入状态。
5. 对话结束后进入知情同意。
6. 三条条款必须先播放，才能点击“已理解并确认”。
7. 完成三条后在 Canvas 区域手写签名并提交。
8. 确认进入完成页并显示知情同意已签名。

## 5. 传统问卷验收路径

1. 使用任务 `T2026080002` 核验身份。
2. 进入传统问卷，确认仅包含：
   - 入院评估单；
   - ADL日常生活能力；
   - 跌倒/坠床风险。
3. 输入年龄后刷新页面，确认答案和进度恢复。
4. 选择“有过敏史”，确认动态显示过敏详情；改为“没有”，确认详情题隐藏且不计入必填总数。
5. 尝试空题进入下一组，确认出现必填提示。
6. 完成全部可见题目，确认进度为 `7/7` 后点击“检查并提交”。
7. 确认进入知情同意页。
8. 点击“我不理解”，确认显示已通知护士且当前进度已保存。

## 6. 住院助手安全边界

1. 进入 `/patient/assistant`。
2. 询问“开水房在哪里”，确认返回住院生活指引。
3. 询问“我胸痛应该吃什么药”，确认助手拒绝提供诊断或用药建议，并要求联系护士。

## 7. 响应式和异常状态

- 桌面端建议使用 1440×900。
- 手机端使用 390×844，重点检查患者底部导航、输入区、签名区和护士横向导航。
- 使用浏览器离线模式，确认顶部出现：

```text
网络连接已中断，当前内容已保存在本机；恢复连接后可继续操作。
```

- 恢复在线后横幅应自动消失。
- 访问不存在路由，确认显示自定义404页面。
- 关键流程中浏览器控制台不应出现 Error。

## 8. 重置演示数据

医护端进入“系统配置”，点击“重置演示数据”。该操作会恢复任务、问卷草稿、对话、复核和质量评价的初始演示状态。

如需完全清理单个浏览器，也可删除以下 localStorage：

- `user-storage`
- `task-storage`
- `chat-storage`
