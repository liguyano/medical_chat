# 前端原型快速测试指南

## 启动项目

```bash

cd D:\A-AICodeWork\medical-evaluate\frontend

# 启动开发服务器
npm run dev
```

访问地址: **http://localhost:3000**

---

## 测试路径 1: 护士端完整流程

### 1. 登录系统
- 访问: http://localhost:3000
- 输入任意用户名和密码（如: `nurse` / `123456`）
- 点击"登录"按钮

### 2. 查看工作台
- 自动跳转到工作台页面
- 查看 4 个统计卡片:
  - 总任务数
  - 待开始任务
  - 待审核任务
  - 已完成任务
- 查看"我的任务"列表（显示最近任务）

### 3. 任务管理
- 点击左侧导航"任务管理"
- 使用顶部筛选按钮切换不同状态:
  - 全部
  - 待开始
  - 进行中
  - 待审核
  - 已完成
- 观察任务卡片的不同状态显示

### 4. 创建新任务
- 点击"创建任务"按钮
- 填写患者信息:
  - 患者姓名: 张三
  - 性别: 男
  - 年龄: 65
  - 床号: 01床
  - 住院号: 12345678
  - 诊断: 冠心病
- 选择采集方式:
  - **AI 对话采集**: 智能对话引导
  - **传统表单**: 直接填写量表
- 点击"创建任务"

### 5. 查看任务详情
- 从任务列表点击任意任务卡片
- 查看完整的患者信息和任务信息
- 根据任务状态操作:
  - **待开始**: 点击"开始任务"或"生成二维码"
  - **进行中**: 查看实时进度
  - **待审核**: 审核 AI 提取的数据，点击"通过审核"或"退回修改"
  - **已完成**: 查看评估报告、生成护理计划

## 测试路径 2: 患者端 AI 对话模式

### 1. 获取任务编号
- 从护士端创建任务后，记下任务编号（如: `TASK-001`）
- 或使用快速测试按钮的预设任务编号

### 2. 患者端入口
- 访问: http://localhost:3000/patient
- 方式 1: 输入任务编号后点击"开始评估"
- 方式 2: 点击"AI 对话"快速测试按钮

### 3. AI 对话评估
- 阅读欢迎消息（小医的自我介绍）
- 观察顶部进度条和阶段标记
- 进行对话交互:
  - **文字输入**: 在底部输入框输入回答，点击发送
  - **语音输入**: 点击麦克风按钮开始录音（当前为模拟）
- 观察对话气泡:
  - AI 消息在左侧（蓝色头像）
  - 患者消息在右侧（橙色背景）
  - CICARE 阶段徽章（C/I/C/A/R/E）
  - 结构化答案提取展示

### 4. 测试对话流程
**示例对话**:
```
AI: 您好！我是您的智能护理助手小医...准备好了吗？
患者: 准备好了

AI: 好的，我了解了。请问您今年多大年龄？
患者: 65岁

AI: 谢谢。请问您有没有过敏史？
患者: 有，我对青霉素过敏

AI: 明白了。您目前有什么不舒服的症状吗？
患者: 最近胸痛，活动后加重
```

### 5. 观察交互效果
- AI 回复时的加载动画（三个跳动的点）
- 消息的渐入动画
- 进度条的实时更新
- 结构化答案的提取和显示

## 测试路径 3: 患者端传统表单模式

### 1. 进入表单页面
- 访问: http://localhost:3000/patient
- 点击"传统表单"快速测试按钮
- 或输入传统表单任务编号

### 2. 分步填写量表
**第 1 部分: 基本信息**
- 年龄: 65
- 性别: 选择"男"

**第 2 部分: 过敏史**
- 是否有药物过敏史: 选择"有"
- 详细描述: `青霉素过敏，出现皮疹和呼吸困难`
  - 注意: 只有选择"有"时，详细描述题目才会显示（**条件逻辑**）

**第 3 部分: 既往病史**
- 慢性疾病（多选）:
  - ✓ 高血压
  - ✓ 糖尿病
  - ✓ 冠心病

**第 4 部分: 生活习惯**
- 是否吸烟: 选择"从不吸烟"（0分）
- 是否饮酒: 选择"偶尔饮酒"（2分）

**第 5 部分: 当前症状**
- 主要不适症状: `胸痛已持续3天，活动后加重，伴有气短`

### 3. 测试功能点
- **必填验证**: 不填必填项，点击"下一步"会显示错误提示
- **数值验证**: 年龄输入超出范围（0-150）会提示错误
- **条件逻辑**: 过敏史选择"无"时，详细描述不显示
- **分步导航**: 
  - 点击"下一步"进入下一章节
  - 点击"上一步"返回上一章节
- **进度显示**: 顶部显示"第 X / 5 部分"和百分比进度条

### 4. 提交评估
- 在最后一个章节，按钮变为"提交评估"
- 点击提交后显示加载状态
- 跳转到完成页面

## 常见问题

### Q1: 页面空白或报错？
**A**: 检查是否正确启动了开发服务器，访问 http://localhost:3000

### Q2: 任务列表为空？
**A**: 点击"创建任务"添加新任务，或使用快速测试按钮查看预设任务

### Q3: 对话没有 AI 回复？
**A**: 当前为模拟回复，会在 1 秒后随机返回一条预设回复

### Q4: 表单提交后跳转失败？
**A**: 检查浏览器控制台是否有错误，确认所有必填项已填写

### Q5: 移动端显示异常？
**A**: 使用浏览器的响应式模式（F12 → 设备工具栏）测试移动端
