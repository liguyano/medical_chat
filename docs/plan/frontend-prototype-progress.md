## 6. 原型边界

以下内容不属于本次前端原型的真实生产能力：

- 未连接 HIS、EMR、后端 API、数据库和统一身份认证。
- AI回复为确定性前端脚本，分段显示为 SSE 视觉模拟。
- 语音、人脸识别、二维码和条款播报为交互占位或模拟。
- 计分、风险规则和护理建议仍需护理团队审批后才能用于临床。
- Canvas 签名仅用于原型演示，不构成有效电子签名或法律存证。
- 审计记录目前为前端状态模型，正式系统需由后端不可篡改地保存。
