# 护士端对话逐条质评与整体质量评价开发计划

## 需求范围

护士在实时监控中查看患者与 AI 的对话时，可以选中某条 AI 消息，对该条消息进行 1～5 分评价、快速问题标签和自由备注；原有 AI 质量评价页面保留为整次会话/评估结果的总体评价入口，并优化为更快捷的离散分值选择。逐条评价和整体评价都需要支持 Mock 与 API 两种数据模式，API 模式落库并可更新同一护士已有评价。
