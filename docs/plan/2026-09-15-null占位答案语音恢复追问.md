# null 占位答案语音恢复追问修复计划

## 1. 问题确认

- [ ] 1.1 确认 `answer_text="null"` 当前会被 `valid_assessment_answer_condition()` 计为有效答案。
- [ ] 1.2 确认 VoiceTurnGuard 仍以 `remaining_question_ids` 决定是否恢复追问。

## 2. 回归测试

- [ ] 2.1 增加结构化答案有效性回归测试：SQL `NULL`、空字符串和文本占位值 `null` 均不得计为有效答案。
- [ ] 2.2 保留普通非空文本、布尔 `False`、数值 `0` 等既有有效值语义不变。

## 3. 实现

- [ ] 3.1 仅修改结构化进度有效答案条件，允许数据库继续保存文本 `null`，但在进度计算中按未回答处理。
- [ ] 3.2 文本占位判断忽略大小写与首尾空格，例如 `null`、`NULL`、` null ` 均视为未回答。
- [ ] 3.3 不改 Extraction 持久化行为，不删除历史 `null` 记录，不改 VoiceTurnGuard 恢复架构。

## 4. 验证

- [ ] 4.1 定向测试确认 `null` 不进入 answered 集合。
- [ ] 4.2 确认 remaining 仍可被 VoiceTurnGuard 映射为下一道恢复问题。
- [ ] 4.3 检查相关回归测试无异常。
