# 话题式护理评估实施计划

## 已确认方案
目标：借鉴论文的自然话题过渡，将护理问题融入吃饭、起居、活动等日常话题，避免逐题念问卷。用户已批准开始实施。当前 main 以 backup/main-before-topic-dialogue-20261019 本地分支备份，开发基于 dev，不合并 main、不推送。

架构：在 Dialog 共享提示词中定义话题引导策略和示例，文本首问与后续指令同步接入，实时语音通过既有共享入口获得同样规则。Schedule 按生活主题规划并允许相关过渡；Extraction 继续逐题依据患者原话抽取，不凭场景推测。保留现有题号关联、数据库进度和完成工具，不新增随机闲聊循环或修改评分。

技术：Python、现有 Dialog / Schedule / Extraction 模型及 pytest。
