# 量表选项计分与 CGA 报告展示修复计划

## 背景
当前 AI 对话抽取将选择题的临床分数保存在 `assessment_answer_option.clinical_score`，但 `ExtractionResultWriter.calculate_scores()` 只累计 `assessment_answer.clinical_score`，导致已回答的居家环境等选项计分量表错误显示 0 分。报告页面还会重复拼接提交摘要和分数解释。

## 1. 方案确认
- [x] 1.1 确认 `main` 已合并 CGA 页面改造，基于它创建独立修复分支。
- [x] 1.2 核对 AI 选项得分快照、总分生成、报告事实聚合、前端格式化路径。
- [x] 1.3 明确缺失分数和真实 0 分的区别；不将跨量表固定阈值套用于无专属规则的量表。

## 2. 后端修复
- [ ] 2.1 为计分题从真实选中选项快照汇总分值，同时支持原有非选择题计分，避免重复相加。
- [ ] 2.2 全部必填非派生题尚未答完、没有计分题或计分依据缺失时，不写入默认 0 分，清除旧的无效总分。
- [ ] 2.3 仅按当前量表专属规则生成风险解释；没有专属风险等级规则时不伪造高、中、低风险。
- [ ] 2.4 新版报告生成时刷新同任务历史 AI 提交的已选选项分数（不覆盖旧报告快照），供重新生成任务 84 等已完成报告使用。

## 3. 前端修复
- [ ] 3.1 CGA 结果展示去重，避免 `result_summary` 和 `scores.interpretation` 内容相同时重复。
- [ ] 3.2 已采集但无有效总分的量表明确显示“未完成计分”；没有该量表时继续显示“未进行相关量表”。
- [ ] 3.3 保留真实 0 分，并在其他相关摘要视图遵循相同的缺失分数语义。

## 4. 回归测试与文档
- [ ] 4.1 测试单选、多选、混合计分、真实 0 分、缺分与不完整量表。
- [ ] 4.2 测试 CGA 结果去重、完成而无分数、未开展量表。
- [ ] 4.3 尝试执行后端与前端测试、类型检查；无法运行的步骤如实记录。
- [ ] 4.4 更新 `backend/AGENTS.md` 和 `frontend/AGENTS.md` 相应约定，核对 diff，不合并 main。

## 数据与安全
- 不写入任何演示患者个人信息或真实报告附件。
- 不修改既有报告版本；历史任务须重新生成新版报告才能获得更正分数。
- 如护士最终确认答案与旧 AI 选项不一致，不应把旧 AI 分数冒充最终分数。
