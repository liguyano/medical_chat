# 患者对话固定轮数与后台阻塞

## 现象

患者回答达到预设问答轮数后，Dialog 直接结束；ExtractionAgent 或 Schedule Agent 失败时，患者侧等待 AI 不返回。

## 根因

- Dialog Runner 以问题数组下标和最后一题判断完成，没有查询结构化 `AssessmentAnswer`。
- 患者消息使用 `Schedule -> group(Dialog + Extraction)` 链，Dialog 被后台 Agent 前置依赖阻塞。
- 进度统计把答案行存在误当作有效答案，空值和低置信度结果可能推进完成。

## 修复

- 新增 `assessment_progress_service.py`，统一按必填、非派生、有效结构化答案计算进度。
- 三个 Agent 独立投递，各自重试；Dialog 读取最后一次成功引导，读取不到继续对话。
- 结束语生成并落库成功后才提交会话和任务完成状态。

## 回归

- 19 项后端集成测试和 169 项后端单元测试通过。
- 真实任务 `96` 验证后台抽取耗时约 10 秒时 Dialog 仍在约 1 秒内返回下一问，随后进度异步更新。
