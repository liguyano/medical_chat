# 语音异常切换文字：诊断与复现

## 已确认的控制行为
浏览器到后端连接失败、上游错误或音频消息处理失败都会进入文字降级。当前浏览器没有自动重连。后端到Qwen连接在ConnectionClosed时串行重建一次，建连或重发失败会向外传播。模型error事件也可触发前端降级，并不一定代表网络断开。截图不足以判断当次原因。

## 使用方法
1. 重启后端使新增日志初始化生效；刷新患者页面加载新浏览器代码。无需更改量表或新建任务。
2. 再次发生故障时，记下时间，查看 `backend/logs/voice-diagnostics-<PID>.jsonl`。UTC时间比北京时间少8小时。轮转备份扩展名为 .1/.2/.3；这些日志已被Git忽略。
3. 查找同一 session_id 的 browser_disconnected/browser_handler_failed/gateway_text_fallback，以及 upstream_disconnected、upstream_reconnect_start/success/failed 和 upstream_event。连接编号及previous_connection_id可串联建连尝试。关闭码1006只说明异常断开，不能单凭它认定内网穿透故障。
4. 浏览器控制台查 `[voice-diagnostic]`，或读取 `sessionStorage.getItem('medical:voice-diagnostics')`，查看 transport_closed的code/wasClean、microphone_failed的errorType、server_error的code和出错前state。记录只留在当前标签、最多100条，没有自动上传后端；标签关闭即丢失。

## 边界
不补造过去日志，不记录音频、患者发言、提示词、密钥或原始错误消息。操作系统提供的关闭原因文本不直接记录，避免敏感内容泄露。HTTP握手可记录状态码和异常类别，供应商业务错误记录错误码/事件号。诊断插桩不等于已修复重连，不保证当前截图的问题不会再发生。

## 验证及审查
日志白名单持久化、写盘无权限降级、重连失败及新旧连接编号回归；既有语音和前端回归。独立审查提出的文件初始化影响启动、多进程轮转冲突、连接指标混用均已修复。未调用真实模型、未使用患者录音、未启动或停止用户服务。
