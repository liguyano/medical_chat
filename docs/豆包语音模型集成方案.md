### 1.1 能力评估

| 能力项 | 是否支持 | 说明 |
|--------|---------|------|
| 语音输入 | ✅ | 支持PCM 16kHz 16bit单声道 / Opus格式 |
| 语音输出 | ✅ | 支持PCM / Opus格式音频流 |
| 文本转录 | ✅ | 输入语音自动转录为文本（`input.audio.transcription.completed`） |
| 文本输出 | ✅ | 同步返回AI回复的文本内容（`response.text.delta`） |

| 工具调用 | ✅ | 支持Function Call（`response.function_call`） |
| 上下文记忆 | ✅ | 通过`conversation_id`维持多轮对话 |
| 动态约束注入 | ✅ | `session.update`可更新系统提示词 |
| 实时打断 | ✅ | 患者可随时打断AI讲话 |

**结论**: 豆包API完全满足本系统需求，无需额外ASR/TTS服务。

## 二、通信协议

### 2.1 WebSocket连接

**连接URL**: `wss://openspeech.bytedance.com/api/v1/tts/ws_binary`

**认证方式**: HTTP Header
```
Authorization: Bearer {api_key}
```

**消息格式**: JSON

**连接生命周期**:
```
1. 创建会话 (session.create)
   ↓
2. 发送音频输入 (input.audio.buffer.append)
   ↓
3. 提交输入 (input.audio.buffer.commit)
   ↓
4. 接收响应流 (response.text.delta / response.audio.delta)
   ↓
5. 工具调用（可选）(response.function_call -> conversation.item.create)
   ↓
6. 更新会话（可选）(session.update)
   ↓
7. 关闭会话 (session.close)
```

## 四、技术实现

### 4.1 核心类设计

```python
# backend/app/engines/doubao_voice_engine.py

import asyncio
import websockets
import json
import base64
from typing import AsyncGenerator, Dict, List
from abc import ABC, abstractmethod

class DialogEngine(ABC):
    """对话引擎抽象基类"""
    
    @abstractmethod
    async def create_session(self):
        """创建对话会话"""
        pass
    
    @abstractmethod
    async def send_input(self, input_data):
        """发送用户输入"""
        pass
    
    @abstractmethod
    async def stream_response(self) -> AsyncGenerator[Dict, None]:
        """流式接收响应"""
        pass
    
    @abstractmethod
    async def close_session(self):
        """关闭会话"""
        pass


class DoubaoVoiceEngine(DialogEngine):
    """豆包实时语音全双工对话引擎"""
    
    def __init__(self, api_key: str, model: str = "doubao-voice-v1"):
        self.api_key = api_key
        self.model = model
        self.ws_url = "wss://openspeech.bytedance.com/api/v1/tts/ws_binary"
        self.session_id = None
        self.conversation_id = None
        self.websocket = None
        self.system_prompt = ""
        self.tools = []
        
    async def create_session(self):
        """创建对话会话"""
        payload = {
            "type": "session.create",
            "session": {
                "model": self.model,
                "instructions": self.system_prompt,
                "voice": "female_calm",  # 女声、平静、亲切
                "tools": self.tools,
                "audio_format": {
                    "input": "pcm16",  # PCM 16kHz 16bit 单声道
                    "output": "pcm16"
                }
            }
        }
        
        self.websocket = await websockets.connect(
            self.ws_url,
            extra_headers={"Authorization": f"Bearer {self.api_key}"}
        )
        
        await self.websocket.send(json.dumps(payload))
        response = await self.websocket.recv()
        result = json.loads(response)
        
        self.session_id = result["session"]["id"]
        self.conversation_id = result["session"]["conversation_id"]
        
        logger.info(f"Doubao session created: {self.session_id}")
        return self.session_id
    
    async def send_input(self, audio_data: bytes):
        """发送语音输入"""
        if not self.websocket:
            await self.create_session()
        
        # 1. 发送音频数据
        payload = {
            "type": "input.audio.buffer.append",
            "event_id": f"audio_{int(time.time() * 1000)}",
            "audio": base64.b64encode(audio_data).decode()
        }
        await self.websocket.send(json.dumps(payload))
        
        # 2. 提交音频输入（触发模型推理）
        commit_payload = {
            "type": "input.audio.buffer.commit"
        }
        await self.websocket.send(json.dumps(commit_payload))
    
    async def stream_response(self) -> AsyncGenerator[Dict, None]:
        """流式接收模型响应"""
        while True:
            try:
                message = await asyncio.wait_for(
                    self.websocket.recv(),
                    timeout=30.0
                )
                
                event = json.loads(message)
                event_type = event.get("type")
                
                # 患者输入转录完成
                if event_type == "input.audio.transcription.completed":
                    yield {
                        "type": "user_transcript",
                        "content": event["transcript"],
                        "timestamp": event.get("timestamp")
                    }
                
                # AI文本增量输出
                elif event_type == "response.text.delta":
                    yield {
                        "type": "text",
                        "content": event["delta"],
                        "timestamp": event.get("timestamp")
                    }
                
                # AI音频增量输出
                elif event_type == "response.audio.delta":
                    yield {
                        "type": "audio",
                        "audio_data": base64.b64decode(event["delta"]),
                        "timestamp": event.get("timestamp")
                    }
                
                # 工具调用
                elif event_type == "response.function_call":
                    yield {
                        "type": "tool_call",
                        "tool_name": event["name"],
                        "arguments": json.loads(event["arguments"]),
                        "call_id": event["call_id"],
                        "timestamp": event.get("timestamp")
                    }
                
                # 响应完成
                elif event_type == "response.done":
                    yield {
                        "type": "response_done",
                        "timestamp": event.get("timestamp")
                    }
                    break
                
                # 错误处理
                elif event_type == "error":
                    logger.error(f"Doubao error: {event}")
                    yield {
                        "type": "error",
                        "error_code": event.get("error", {}).get("code"),
                        "message": event.get("error", {}).get("message")
                    }
                    break
                    
            except asyncio.TimeoutError:
                logger.warning("Doubao response timeout")
                yield {
                    "type": "error",
                    "error_code": "TIMEOUT",
                    "message": "模型响应超时"
                }
                break
            except Exception as e:
                logger.error(f"Doubao stream error: {e}")
                break
    
    async def send_tool_result(self, call_id: str, result: Dict):
        """发送工具调用结果"""
        payload = {
            "type": "conversation.item.create",
            "item": {
                "type": "function_call_output",
                "call_id": call_id,
                "output": json.dumps(result, ensure_ascii=False)
            }
        }
        await self.websocket.send(json.dumps(payload))
    
    async def update_session(self, instructions: str = None, tools: List = None):
        """更新会话配置（动态注入约束提示）"""
        payload = {
            "type": "session.update",
            "session": {}
        }
        
        if instructions:
            payload["session"]["instructions"] = instructions
        
        if tools:
            payload["session"]["tools"] = tools
        
        await self.websocket.send(json.dumps(payload))
    
    async def close_session(self):
        """关闭会话"""
        if self.websocket:
            payload = {"type": "session.close"}
            await self.websocket.send(json.dumps(payload))
            await self.websocket.close()
            logger.info(f"Doubao session closed: {self.session_id}")
```

// 前端采集患者语音
let mediaRecorder;
let audioChunks = [];

async function startRecording() {
  const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
  mediaRecorder = new MediaRecorder(stream, {
    mimeType: 'audio/webm;codecs=opus'
  });
  
  mediaRecorder.ondataavailable = (event) => {
    audioChunks.push(event.data);
  };
  
  mediaRecorder.onstop = async () => {
    const audioBlob = new Blob(audioChunks, { type: 'audio/webm' });
    const arrayBuffer = await audioBlob.arrayBuffer();
    
    // 转换为PCM格式（需要Web Audio API）
    const audioContext = new AudioContext({ sampleRate: 16000 });
    const audioBuffer = await audioContext.decodeAudioData(arrayBuffer);
    const pcmData = audioBuffer.getChannelData(0);
    
    // 发送到后端
    await sendAudioToBackend(pcmData);
    
    audioChunks = [];
  };
  
  mediaRecorder.start();
}

function stopRecording() {
  mediaRecorder.stop();
}

async function sendAudioToBackend(pcmData) {
  const base64Audio = btoa(String.fromCharCode(...new Uint8Array(pcmData.buffer)));
  
  await fetch('/api/dialog/audio', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      session_id: sessionId,
      audio_data: base64Audio
    })
  });
}

### 5.2 SSE接收AI音频并播放

```javascript
// SSE订阅对话流
const eventSource = new EventSource(`/api/sse/dialog/${sessionId}`);

const audioContext = new AudioContext({ sampleRate: 16000 });
const audioQueue = [];
let isPlaying = false;

eventSource.addEventListener('dialog_message', (event) => {
  const data = JSON.parse(event.data);
  
  // 文本显示
  if (data.type === 'text') {
    displayText(data.content);
  }
  
  // 音频播放
  if (data.type === 'audio') {
    const pcmData = atob(data.audio_data);
    const audioBuffer = new Float32Array(pcmData.length);
    
    for (let i = 0; i < pcmData.length; i++) {
      audioBuffer[i] = pcmData.charCodeAt(i) / 32768.0 - 1.0;
    }
    
    audioQueue.push(audioBuffer);
    if (!isPlaying) {
      playNextAudio();
    }
  }
});

async function playNextAudio() {
  if (audioQueue.length === 0) {
    isPlaying = false;
    return;
  }
  
  isPlaying = true;
  const pcmData = audioQueue.shift();
  
  const audioBuffer = audioContext.createBuffer(1, pcmData.length, 16000);
  audioBuffer.getChannelData(0).set(pcmData);
  
  const source = audioContext.createBufferSource();
  source.buffer = audioBuffer;
  source.connect(audioContext.destination);
  
  source.onended = () => {
    playNextAudio();
  };
  
  source.start();
}
```

## 七、注意事项

### 7.1 音频格式转换
- **前端采集**: WebRTC默认输出Opus/WebM格式
- **豆包输入**: 需要PCM 16kHz 16bit单声道
- **解决方案**: 使用Web Audio API在前端转换，或后端使用FFmpeg

### 7.2 连接稳定性
- WebSocket可能因网络波动断线
- **解决方案**: 实现自动重连机制，重连时使用`conversation_id`恢复上下文

### 7.3 并发限制
- 豆包API可能有并发连接限制
- **解决方案**: 在Dialog Agent层实现连接池管理

### 7.4 工具调用延迟
- 工具调用需要等待后端执行并返回结果
- **解决方案**: 前端显示"正在获取宣教材料..."等加载提示
