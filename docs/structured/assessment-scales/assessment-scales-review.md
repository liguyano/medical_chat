## 1. 住院患者营养风险筛查表（NRS2002）

来源：`docs/文档/评估表/10.1和2营养风险筛查表（NRS2002）.pdf`

结构化文件：`docs/structured/assessment-scales/nrs2002.json`

| `weight_kg` | 体重，单位kg |
| `bmi` | BMI，单位kg/m2 |
| `bedridden` | 卧床 |

### 初步营养筛查

规则：以下任意一项回答“是”，进入第二步正式筛查；全部回答“否”，说明患者目前无营养风险，1周后复查。

| 字段 ID | 问题 | 类型 |
| --- | --- | --- |
| `bmi_lt_18_5` | BMI<18.5kg/m2 | 是/否 |
| `weight_loss_3_months` | 过去3个月有体重下降 | 是/否 |
| `intake_reduced_last_week` | 过去一周有摄食减少 | 是/否 |
| `severe_disease_icu` | 有严重疾病（如需ICU治疗） | 是/否 |

### 正式筛查评分

总分公式：`疾病严重程度评分 + 营养状态受损评分 + 年龄评分`

| 评分项 | 分值 | 选项/条件 |
| --- | --- | --- |
| 疾病严重程度 | 0 | 未达到1分、2分、3分标准 |
| 疾病严重程度 | 1 | 一般肿瘤；髋关节骨折；血液透析；糖尿病；慢性病有急性并发症；或慢性病患者因并发症住院、虚弱但不需卧床 |
| 疾病严重程度 | 2 | 血液恶性肿瘤；严重肺炎；腹部大手术；脑卒中；或卧床患者，如大手术后 |
| 疾病严重程度 | 3 | 颅脑损伤；骨髓移植；重症监护患者（APACHE>10）；或加强病房机械通气支持患者 |
| 营养状态受损 | 0 | 未达到1分、2分、3分标准 |
| 营养状态受损 | 1 | 近3个月内体重减轻>5%；或最近1周进食量较需要量减少25%~50% |
| 营养状态受损 | 2 | 近2个月内体重减轻>5%；或BMI 18.5~20.5；或最近1周进食量较需要量减少50%~75% |
| 营养状态受损 | 3 | 近1个月内体重减轻>5%；或3个月内减轻>15%；或BMI<18.5；或血清白蛋白<35g/L；或最近1周进食量较需要量减少75%~100% |
| 年龄评分 | 0 | 年龄<=70岁 |
| 年龄评分 | 1 | 年龄>70岁 |

### 结果解释

| 条件 | 结果 |
| --- | --- |
| 总分>=3 | 患者有营养不良风险，需营养支持治疗 |
| 总分<3 | 若患者将接受重大手术，则每周重新评估营养状况 |

| 皮肤护理 | 每天定时检查皮肤情况，特别是受压部位；帮助搞个人卫生；当皮肤弄脏时及时清洁；干性皮肤使用皮肤润肤霜；受刺激物浸润区域使用皮肤保护物；纸尿片或纸尿裤；尿套；留置导尿管；大便失禁者安装造口袋或收集器材；其他 |

## 3. 入院评估单

来源：`docs/文档/评估表/入院评估单.pdf`

结构化文件：`docs/structured/assessment-scales/admission-assessment.json`

说明：该 PDF 为扫描图片版，普通文本抽取为空。本结构化结果来自渲染页面后的人工视觉转录，需重点审批。

### 表单定位

入院评估单不是单一计分量表，而是入院护理信息采集表。它包含基础情况、护理评估、量表结果摘要、护理重点、住院告知和签名字段。

### 主要分组

| 分组 | 内容 |
| --- | --- |
| 基本情况 | 性别、年龄、职业、婚姻、宗教、教育程度、资料来源、入院方式、陪同人、日常照顾者、诊断 |
| 护理评估 | 生命体征、身高体重BMI、过敏史、既往史、意识状态、语言表达、饮食、口腔黏膜、吞咽困难、睡眠、排泄、四肢活动、自理能力、皮肤状况、嗜好、药物依赖等 |
| 量表评估情况 | ADL评分、跌倒评分、压疮评分、疼痛评分、营养评分、误吸风险评分，以及是否通知医生 |
| 护理重点 | 基础护理、专科护理、患者安全、护理交接班重点、提醒患者及家属关注事项 |
| 住院告知 | 住院须知、介绍主管医生及主管护士、无烟医院、优质护理服务病房、消防安全等 |

### 量表结果触发通知医生条件

| 字段 | 条件 |
| --- | --- |
| ADL评分 | 总分<=40分 |
| 跌倒评分 | 总分>=40分 |
| 压疮评分 | 总分<=12分 |
| 疼痛评分 | 总分>=4分 |
| 营养评分 | MNA-SF总分<7分，或NRS2002>=3分，或STRONkids>=1分 |
| 误吸风险评分 | SSA总分>=19分 |

### 待审批点

| 项目 | 说明 |
| --- | --- |
| 抽取方式 | 扫描件人工视觉转录，需重点确认字段是否遗漏 |
| 字段类型 | 部分字段是单选还是多选需按实际业务录入习惯确认 |
| 量表关联 | 入院评估单引用疼痛、营养、误吸风险等量表，但当前来源目录只包含部分量表原件 |

## 后续入库建议

审批通过后，建议按三类结构导入 PostgreSQL：

| 类型 | 建议用途 |

| `risk_scale` | 有总分、风险等级或干预建议的风险评分量表 |
| `ability_scale` | 有总分、能力等级解释的能力评价量表 |

| 项目 | 原因 |
