## 统一设计原则

1. 首页先展示“下一步动作”和安全风险，再展示完整数据。
2. 任务、患者、监控页面统一使用“状态 + 风险 + 下一步”三元信息。
3. 红色和琥珀色只用于患者安全、逾期、人工介入和待审核等需要关注的状态。
4. 页面中的字段应来自领域接口，不让后端原始 DTO 或 JSON 结构直接成为用户界面。
5. 评估量表采用数据库版本化管理，UI 使用结构化编辑器；原始 JSON 仅作为导入、导出和审计材料，不作为日常编辑入口。

当前仓库此前不存在 `docs/ui` 目录，因此本次没有移动、覆盖或删除任何历史 UI 文件。
