# 患者端图标清单

图标统一收录于 `患者端图标集.svg`，每个符号使用 `viewBox="0 0 24 24"`，默认 `currentColor` 描边，适合直接作为 `<svg><use href="...#icon-id" /></svg>` 使用。

高频图标另提供于 `独立/` 目录，前端可以直接引用独立 SVG，不需要处理 Sprite。

## 规范

- 默认尺寸：24×24px。
- 紧凑按钮：20×20px。
- 底部导航：22×22px。
- 大按钮：28×28px。
- 描边宽度：1.8px，圆角线帽和圆角连接。
- 颜色由外层 CSS 控制，不在图标内部写死颜色。
- 小图标不提供超大位图，移动端直接使用 SVG。
