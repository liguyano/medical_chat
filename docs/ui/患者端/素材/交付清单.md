## 直接使用约定

- SVG 图标默认 `currentColor`，外层控制颜色；不修改 SVG 内部颜色。
- 图标建议使用 20、24、28px 三档；触控按钮整体不小于 44×44px。
- WebP 插画保留透明通道，移动端显示宽度建议不超过 256px。
- `语音Orb-状态集.svg` 与 `语音控制栏.svg` 是视觉验收基准，不作为页面截图使用。
- 页面稿仅用于对照布局，不应被当作生产素材切图。
