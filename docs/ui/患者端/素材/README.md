# 患者端素材包

本目录用于稳定复现患者端 UI 设计，素材按用途拆分：

- `图标/`：24×24 SVG 图标集，不提供超大位图。
- `组件/`：语音 Orb、语音控制栏、设计令牌和部件规格。
- `状态/`：加载、空任务、错误、暂停、完成和只读状态图形。
- `插画/`：移动端压缩后的透明 WebP 插画。

开发时可以先将 SVG 复制到前端的 `public/assets/patient/icons/`，将 WebP 复制到 `public/assets/patient/illustrations/`；设计稿目录本身不参与生产构建。

完整文件、原型对应关系和尺寸约束见 [`交付清单.md`](./交付清单.md)。
