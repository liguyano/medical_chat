# 患者端部件规格

## 语音 Orb

- 默认直径：168px（手机宽度 390px 时）。
- 状态颜色：待机橙色、正在听青绿色、AI 思考蓝色、AI 播报绿色、异常琥珀色。
- 动画：呼吸缩放 1.0 → 1.04，周期 2.4s；播报状态增加低频横向波纹。
- 禁止使用高频闪烁、霓虹渐变和持续旋转。
- 页面必须同时显示文字状态，不依赖动画判断当前状态。

## 语音控制栏

- 控件最小触控区域：44×44px。
- 主麦克风按钮：80×80px，始终位于底部中央。
- 左侧：切换文字；右侧：打断播报。
- AI 播报时右侧按钮切换为“打断播报”；监听时显示“结束回答”。
- 转写待确认时，在控制栏上方显示转写卡片，提供“确认发送”和“重新说一遍”。

## 患者卡片

- 卡片圆角 24px，内部间距 16px。
- 进度条高度 8px，圆角全圆。
- 主操作按钮使用胶囊按钮，次操作使用描边按钮。
- 对老年患者保持正文 16px、辅助说明 13px 以上。

## 导航

- 底部导航高度 72px + 安全区。
- 首页、任务、住院助手三个入口保持固定。
- 激活态使用 `--patient-primary` 和 `--patient-primary-tint`，不使用纯黑。

### 触控和可访问性

- 可点击控件最小 44×44px；语音主麦克风为 80×80px。
- 正文最小 16px，辅助说明不低于 13px。
- 状态图形必须配可读 `aria-label` 或旁边的可见文字。
- AI 语音异常时保留文字输入；“呼叫护士”与“打断播报”必须有不同图标和文案。
