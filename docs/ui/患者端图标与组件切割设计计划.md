# 患者端图标与组件切割设计计划

## 目标

将患者端新版 UI 设计稿中的图标、插画、语音交互部件和通用 UI 组件拆分为前端可直接复用的素材，帮助前端稳定复原患者端原型，而不是依赖整张设计稿猜测尺寸、颜色和交互状态。

本计划覆盖以下患者端场景：

- 身份核验
- 住院服务首页
- 我的护理任务
- 任务详情
- AI 智能评估对话
- 语音交互
- 知情同意确认
- 评估完成
- 住院助手
- 底部导航与通用反馈状态

## 素材目录与命名规则

统一保存于：

`docs/ui/患者端/素材/`

目录约定：

```text
docs/ui/患者端/素材/
├─ 图标/
├─ 插画/
├─ 组件/
├─ 状态/
└─ README.md
```

文件命名规则：

- 新设计：`新版-功能-状态-v1`
- 迭代版本：`新版-功能-状态-v2`
- 历史稿：`旧版-功能-状态-基线-v日期`
- 图标使用稳定英文 ID，避免前端引用因中文文件名变更而失效。
- 禁止覆盖或删除已有设计稿和素材。
