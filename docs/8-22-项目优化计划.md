# 项目优化计划
## 背景
以下是我在调试代码时, 从人工审查角度, 提出的需要优化方案.

## 任务

# 需求范围确认

- AI 对话任务创建后，必须完成 `Schedule prepare -> Dialog preheat -> Dialog opening`，
  首问落库后才对患者端可见。
- 患者端不可见准备中、失败或重试中的 AI 对话任务；传统问卷任务保持原有可见逻辑。
- 医护端可查看三个阶段的状态、量表问题列表、首问内容、失败原因和重试次数。
- 医护端可对准备失败的原任务发起幂等重试，不重复创建任务。
- Agent 临床上下文仅增加当前住院记录的 `diagnosis_snapshot`；不传递过敏史、入院来源、
  护理级别等字段。Prompt 明确该诊断只用于内部评估排序和风险理解，不得向患者宣告诊断
  结论、不得据此自行诊断或调整治疗。
